# Профили, портфолио и рейтинг

`GET /api/directory` — общий публичный каталог для главной и профилей. Главная показывает только резидентов с фотографией и включённым показом карточки; остальные мастера сохраняют публичный профиль и участие в рейтинге. Исторические карточки сохраняют свои URL. `server/master-catalog.json` содержит исходный архив, записи `content/master-*` — изменения администратора, `master_links` — явные связи с зарегистрированными аккаунтами. Связи не создаются по совпадению имён.

В админке → «Пользователи» → «Мастера» → «Привязать аккаунт» владелец выбирает подходящий аккаунт. После привязки имя, город, резидентство и статистика принадлежат аккаунту; в каталоге остаётся одна карточка. Деактивация аккаунта скрывает связанную карточку. Отвязка возвращает архивную карточку. Права аккаунтов и исторические бронирования не переносятся.

Мастер редактирует общие поля в кабинете → «Профиль». «Показывать меня в рейтинге» управляет только рейтингом, публичная ссылка профиля остаётся рабочей. Корона связанного мастера определяется ролью аккаунта. Скрытие карточки администратором управляет главной; публичная страница сохраняется.

`GET /api/ranking?period=all|month` считает подтверждённые бронирования и завершённые сеансы по данным базы. Месяц — календарный месяц Москвы, обе границы включены в SQL условие (нижняя включена, верхняя исключена). Архивным карточкам без аккаунта не создаются фиктивные сеансы. Баллы используются только для сортировки; на сайте отображаются сеансы.

Фотографии: `GET/POST/PATCH /api/me/gallery`, `DELETE /api/me/gallery/:id`. Только владелец может менять свои файлы. До 24 фотографий; разрешены работы и эскизы, подпись до 150 символов. Клиент создаёт JPEG до 1280 px и превью до 320 px; сервер ограничивает размер и проверяет формат. Исходники не отправляются. `GET /api/media/:id?size=thumb` отдаёт превью; без параметра — большую версию. Непубличные поля аккаунта не входят в ответы. Удалённые изображения могут оставаться в кеше до пяти минут.

Резервные копии базы включают фотографии. `scripts/backup-verify.sh` делает pg_dump, восстанавливает архив в отдельную временную базу, проверяет таблицы и удаляет только эту временную базу. Основную базу скрипт не восстанавливает и не изменяет. Секреты и архивы не хранятся в Git. Таймер из `deploy/systemd` запускает проверку ежедневно; состояние проверяется через `systemctl status tattoo-office-backup.timer` и `journalctl -u tattoo-office-backup.service`.

Проверки: `npm test`, `npm run check`, `npm run build`. `npm run build && node tests/ui-foundation.mjs` запускает временную PGlite и Chrome: регистрация → профиль → загрузка → публичное портфолио → рейтинг → бронь → тестовая оплата → ближайшая запись. Проверяет телефон, обе ориентации iPad и компьютер. Chrome должен быть установлен локально. Боевой платёжный режим этим обновлением не включается.

Сервер возвращает `X-Request-ID`. Ошибки 5xx пишутся в журнал с идентификатором, маршрутом и длительностью, без cookies, тела запроса и строк параметров.

При сборке Sharp создаёт WebP-версии архивных портретов и работ шириной 160/320/640 px без увеличения исходника. Имена включают хеш исходного файла; браузер выбирает размер через srcset, просмотрщик открывает исходное фото. Сами исходники не меняются. Новые загрузки мастеров используют отдельное превью из базы.

Ссылку для записи назначает только администратор: для аккаунтов — «Пользователи» → «Изменить», для архивных карточек — «Пользователи» → «Мастера» → «Личное дело». Пользовательский PATCH /me отклоняет изменение ссылки, старые самостоятельно заданные ссылки не используются. Кнопка записи отображается только у резидентов. Выбор обложки убран из настроек профиля.

В профиле указывается дата рождения. Сервер вычисляет публичный возраст на текущую дату Москвы; дата рождения не входит в публичный каталог и рейтинг. Для старых карточек без даты рождения сохраняется прежний возраст до заполнения данных владельцем.

Работы и эскизы редактируются в отдельной вкладке кабинета. У загрузок есть явные кнопки, перетаскивание файлов, предпросмотр и статус выполнения. Глобальный стиль фокуса больше не изменяет радиус панелей.
