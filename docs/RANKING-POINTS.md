# Рейтинг Tattoo Office

Рейтинг рассчитывается на сервере по фактическим оплаченным заказам и текущему содержимому профиля. Это баллы активности, не деньги и не скидка. Резидентство само по себе баллов не даёт.

По умолчанию:

| Действие | Баллы |
| --- | --- |
| Полностью рассчитанная аренда | round(стоимость аренды в ₽ × 70 / 3200) |
| Оплаченная дополнительная услуга | 20 за единицу |
| Оплаченные товары | round(стоимость строки товаров в ₽ × 5 / 1000) |
| Полный профиль | 5 за текущее полное состояние |
| Уникальная работа | 2, до 100 работ |
| Уникальный эскиз | 1, до 20 эскизов |

Полный профиль: имя, фото, город, описание от 80 символов, стиль, стаж и одна загруженная работа. Дата рождения и назначаемый администратором контакт не обязательны для бонуса.

Финансовые баллы появляются только после статуса completed и полного покрытия счёта оплаченными платежами и использованным балансом. Предоплаты, отмены, незакрытые счета, нулевая аренда и тестовые оплаты не учитываются. Повторный callback не увеличивает баллы: расчёт не создаёт событий начисления, а получает итог из первичных записей. Перевод заказа в отменённый/неоплаченный статус убирает его финансовый вклад.

Платежи содержат признак is_test. Для старых платежей без признака финансовые баллы разрешены только для подтверждённых наличных оплат. Старые тестовые и неопределённые онлайн-платежи не переносятся как реальные доходы.

Контент сравнивается по отпечатку изображения, а не ID загрузки. Одинаковое изображение учитывается один раз, при наличии в работах и эскизах — как работа. Удаление уменьшает текущий балл; повторная загрузка восстанавливает тот же вклад. Баллы за архивные, не загруженные пользователем изображения не начисляются.

Веса и лимиты меняются в настройках администратора. Изменения пересчитывают исторический рейтинг. В личном деле мастер видит разбивку и недостающие поля; публичный рейтинг раскрывает баллы без сумм заказов, платёжных реквизитов и личных контактов.

Администратор меняет итог мастера в «Пользователи → Баллы → изменить». Значение — целое от 0 до 10 000 000. Сервер сохраняет разницу между заданным итогом и автоматически заработанными баллами. Следующие действия продолжают приносить баллы; повторное сохранение не дублирует корректировку. Изменение записывается в аудит. Сам мастер не может редактировать эту поправку.

Для исходных карточек без аккаунта баллы хранятся отдельно в content. Привязка настоящего аккаунта использует его собственные баллы, без переноса демонстрационного значения. scripts/seed-demo-points.mjs показывает план; --apply однократно задаёт случайные значения 120–1500 только исходным непривязанным карточкам без ранее заданных баллов. Скрипт не меняет зарегистрированные аккаунты и повторно не перезаписывает итог.
